# Project Landing Page

A responsive landing page for an AI-powered collaborative workspace. It features a hero section, navigation links, calls to action, a workspace preview, and an assistant chat panel.

## Features

- Responsive layout styled with Tailwind CSS.
- Hero section with product messaging and calls to action.
- Workspace dashboard preview with project status and task cards.
- Assistant chat panel markup.

## How to run

This is a static website, so no build tools or package installation are needed.

### Open directly

1. Download or clone this project and open its folder.
2. Double-click `index.html` to open it in your default web browser.

### Run with Visual Studio Code

1. Open the project folder in Visual Studio Code.
2. If you have the **Live Server** extension installed, right-click `index.html` and select **Open with Live Server**.
3. Your browser will open the page. Save changes to the files to see updates.

Tailwind CSS is loaded from a CDN, so an internet connection is required for Tailwind styling.

## Project files

- `index.html` — page structure and content.
- `style.css` — custom styles.
- `script.js` — chat-panel visibility handlers; opening the panel requires a `chat-widget-btn` element.
